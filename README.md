# Global Earthquake Activity Analysis: Magnitude, Depth & Regional Patterns

End-to-end exploratory data analysis (EDA) of worldwide earthquakes
using Python (Pandas, NumPy, Matplotlib, Seaborn, Plotly).

## Problem statement
Where and when do the strongest earthquakes occur, how deep do they start,
and how are magnitude, depth, location and measurement quality related?

## Dataset
- Name: ANSS Comprehensive Earthquake Catalog (ComCat), USGS
- Source: https://earthquake.usgs.gov/earthquakes/search/
- Settings: 2025-01-01 to 2025-12-31, magnitude 4.5+, worldwide, CSV
- Size: 8,561 rows, 22 columns
- Downloaded on: <16-11-26>

## Tools
Python, Jupyter Notebook / Google Colab, Pandas, NumPy, Matplotlib,
Seaborn, Plotly
